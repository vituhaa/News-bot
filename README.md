# Новостной бот для студентов НИУ ВШЭ в Telegram.

## Возможности для пользователя:
1) Создавать новость:
   - Заголовок (не более 200 символов);
   - Основной текст;
   - Категория из списка предложенных;
   - До 10 фотографий формата JPG/PNG или 1 файл формата PDF или DOCX.
2) Редактировать новость;
3) Отправить новость на модерацию.

## Возможности для администратора:
1) Работать с новыми заявками:
   - Одобрить (новость публикуется в указанном телеграм-канале);
   - Вернуть новость на доработку с комментарием;
   - Отклонить новость с комментарием;
   - Выгрузить новость в архив, в котором хранятся медиа-файлы и JSON-файл с данными о созданном посте.
2) Задать ссылку телеграм-канала, куда будут публиковаться новости студентов;
3) Посмотреть список текущих администраторов;
4) Редактировать категории новостей: добавлять новые и удалять из текущего списка.

## Возможности для супер-администратора:
1) Просматривать список текущих администраторов
2) Добавлять и удалять администраторов.

# Начало работы:
Для начала работы с ботом:
1) пользователю нужно ввести команду "/start";
2) администратору - команду "/admin";
3) супер-администратору - команду "/super".
